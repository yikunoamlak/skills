# Skills For Creative Agents

A curated collection of AI agent skills for creative and design work — Ethiopian art generation, mask creation, alter ego analysis, YouTube thumbnail creation, and interview-driven design storytelling.

Install with one command:

```bash
npx skills@latest add yikunoamlak/skills
```

Or install individual skills:

```bash
npx skills@latest add yikunoamlak/skills/afewerk-tekle-painting

npx skills@latest add yikunoamlak/skills/vector-tribal-mask-generator
```

## Ethiopian Art Skills

This collection includes two distinct Ethiopian painting styles:

| Style | Artist | Characteristics |
|-------|--------|-----------------|
| **Afewerk Tekle** | Afewerk Tekle (1932–2012) | Volumetric oil painting, dramatic chiaroscuro, classical realism, stained-glass cubism, jewel-toned colors, monumental dignity |
| **Etsubdink Legesse** | Etsubdink Legesse (contemporary) | Flat 2D painting, bold black outlines, warm earth tones, large almond-shaped eyes, narrative panels, manuscript aesthetic |

**Do not confuse these two styles.** Tekle uses perspective, depth, shadow, and volume. Legesse's work is flat, symbolic, and manuscript-like. Both are masterful but fundamentally different.
