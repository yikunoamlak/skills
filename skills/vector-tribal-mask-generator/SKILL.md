## Implementation Notes

When the user provides an image:

1. **Analyze** the source image for visual language extraction:
   - Identify dominant geometric shapes and proportions
   - Note color relationships and palette mood
   - Extract recurring motifs, patterns, rhythm
   - Understand symmetry approaches
   - Recognize facial structure archetypes

2. **Generate** a collection specification:
   - Define grid dimensions (3×4, 4×4, or 5×5)
   - Establish master color palette (shared across collection)
   - Set proportional guidelines for mask dimensions
   - Define stroke weight and treatment rules
   - Create variation rules for each facial feature

3. **Design** each mask individually:
   - Select face shape from the 5 archetypes
   - Compose unique feature combinations
   - Apply color palette with 5-8 colors per mask
   - Ensure bilateral symmetry
   - Verify closed paths and clean curves

4. **Output** as:
   - SVG file (primary) - clean, layered, scalable
   - PNG export (secondary) - high-res for preview
   - JSON specification (tertiary) - for regeneration/modification
