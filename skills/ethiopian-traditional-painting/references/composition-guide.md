# Composition Guide — Ethiopian Traditional Painting

## Fundamental Principles

Ethiopian painting composition is governed by clarity, balance, and narrative readability. Every element serves the story.

### 1. Flatness Over Depth
- No perspective lines, no vanishing points
- Depth expressed through vertical stacking (higher = farther)
- Background elements are same scale as foreground
- No atmospheric perspective (no fading)

### 2. Balance Over Realism
- Figures evenly distributed
- Symmetrical or near-symmetrical arrangements
- Weight distributed across the frame
- No single area feels empty or overcrowded

### 3. Clarity Over Complexity
- Every figure is distinct and identifiable
- Actions are immediately readable
- Objects are simplified to essentials
- No ambiguous gestures or positions

## Panel Formats

### Single Panel (Portrait)
```
┌─────────────────────┐
│    Ge'ez text       │
│                     │
│    ┌─────────┐     │
│    │  FIGURE │     │
│    │  (upper │     │
│    │  body)  │     │
│    └─────────┘     │
│                     │
│  Simple background  │
└─────────────────────┘
```
- Figure centered or slightly off-center
- Upper body visible (chest and above)
- Direct gaze at viewer
- Simple background element (tree, cross, building)
- Decorative border framing

### Bilateral (Two Groups)
```
┌─────────────────────┐
│                     │
│  LEFT    │  RIGHT   │
│  GROUP   │  GROUP   │
│    ←─────┼─────→    │
│         ALTAR       │
│                     │
└─────────────────────┘
```
- Two groups facing each other
- Central dividing element (altar, throne, tree)
- Balanced number of figures on each side
- Central figure or object slightly larger
- Action flows from sides toward center

### Multi-Row Group
```
┌─────────────────────┐
│  ┌───┐┌───┐┌───┐   │
│  │ F ││ F ││ F │   │  Row 1 (back, slightly higher)
│  └───┘└───┘└───┘   │
│  ┌───┐┌───┐┌───┐   │
│  │ F ││ F ││ F │   │  Row 2 (front)
│  └───┘└───┘└───┘   │
└─────────────────────┘
```
- Figures in rows, back row higher
- Similar head heights within rows
- Even spacing between figures
- Back row slightly smaller or partially hidden

### Grid Narrative (Multi-Panel)
```
┌──────┬──────┬──────┐
│ P1   │ P2   │ P3   │
├──────┼──────┼──────┤
│ P4   │ P5   │ P6   │
├──────┼──────┼──────┤
│ P7   │ P8   │ P9   │
└──────┴──────┴──────┘
```
- Each panel独立 framed with red/terracotta border
- Reading order: left-to-right, top-to-bottom
- Each panel tells one part of the story
- Consistent border width between panels
- Ge'ez text titles above or below panels

### Processional
```
┌─────────────────────┐
│                     │
│  ←←←←←←←←←←←←←←   │
│  F F F F F LEADER   │
│                     │
└─────────────────────┘
```
- Figures moving in one direction
- Leader at front (right side for rightward movement)
- Followers behind in line
- Direction indicated by body angle and foot position
- Objects carried identify the event

## Figure Arrangement Rules

### Head Height
- All figures in the same row: **same head height**
- Back row figures: heads slightly higher than front row
- Important figures: may be slightly larger overall

### Spacing
- **Equal gaps** between figures
- No overlapping bodies (heads may slightly overlap in dense groups)
- Arms and hands may connect figures (holding hands, passing objects)

### Facing
- **Front-facing**: Most common, figures look at viewer
- **Simple profile**: 90° turn, used for action scenes
- **Three-quarter view**: NEVER — this implies depth/perspective

### Hand Position
- **Raised in gesture**: Teaching, blessing, speaking
- **Holding objects**: Identifying attributes (cross, instrument, tool)
- **At sides**: Neutral, waiting, observing
- **Folded in lap**: Seated, contemplative

## Background Zones

### Upper Zone (Sky)
- Warm ivory background
- May contain Ge'ez text as decorative element
- May have stylized clouds (simple curved lines)
- Sun or moon as simple circle

### Middle Zone (Setting)
- Architectural elements (buildings, churches)
- Stylized trees (rounded canopy, straight trunk)
- Mountains as simple triangular forms
- This zone provides context for the narrative

### Lower Zone (Ground)
- Solid warm brown or terracotta
- Simple ground line
- No grass texture or detail
- Figures stand on this zone

## Border System

### Panel Border
- **Color**: Deep red or terracotta
- **Width**: Consistent, typically 3-5% of panel width
- **Pattern**: May contain geometric motifs (zigzags, diamonds, crosses)
- **Function**: Frames the narrative, separates from adjacent panels

### Multi-Panel Borders
- **Outer border**: Thicker, more ornate
- **Inner borders**: Thinner, simpler
- **Corner elements**: May contain cross motifs or decorative squares

### Text Placement
- **Above panel**: Title or identification of scene
- **Below panel**: Description or dialogue
- **Within panel**: Labels on objects or figures
- **Script**: Ge'ez or Amharic, decorative quality

## Narrative Composition Patterns

### Story Sequence
```
Panel 1: Setup (who, where)
Panel 2: Action (what happens)
Panel 3: Climax (key moment)
Panel 4: Resolution (outcome)
```

### Before/After
```
Left panel: Before state
Right panel: After state
```

### Central Focus
```
Central figure: Important person or object
Flanking figures: Witnesses, attendants, supporters
```

### Procession
```
Leader → Followers → Destination
Direction: Left to right (or right to left)
```

## Common Compositional Errors to Avoid

1. **Overlapping bodies** — figures should be distinct
2. **Mixed facing** — don't mix front-facing and profile in same group
3. **Uneven spacing** — gaps should be consistent
4. **Varying head heights** — keep them aligned in rows
5. **Lost edges** — every form must be clearly outlined
6. **Cluttered backgrounds** — keep it simple and symbolic
7. **Empty zones** — distribute elements evenly
8. **Tiny figures** — fill the frame, figures should be prominent
9. **Realistic depth** — no vanishing points, no diminishing scale
10. **Complex gestures** — keep hands and arms simple
