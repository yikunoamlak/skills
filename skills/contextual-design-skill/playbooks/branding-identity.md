# Branding & Identity Context Playbook

## Context ladder
`mark → identity system → touchpoint → customer experience → brand/category/culture`

## Ask
- What does the brand need to be recognized for?
- Where will the identity actually appear?
- Which touchpoints are high-stakes?
- What must remain constant and what can flex?
- What competitors occupy the same visual territory?
- Does the identity need to work in motion, UI, packaging, signage, print, apparel, or environmental applications?

## Recommendations
- Do not judge the logo separately from the identity system.
- Test at real sizes and materials.
- Define behavior: spacing, hierarchy, imagery, type, color, iconography, motion, tone, co-branding.
- Make "premium," "modern," "local," or "technical" measurable through context-specific signals.
- Build a recognizable system, not a collection of isolated assets.
