# Typography & Editorial Context Playbook

## Context ladder
`glyph/letterform → text style → page/spread → publication → reading situation`

## Ask
- What is the reading distance and speed?
- What language/script(s) are involved?
- What content lengths are realistic?
- Is text skimmed, studied, presented, or spoken?
- What are the page dimensions, column structure, and reproduction conditions?
- Does the type need to behave as interface text, display, signage, or body copy?

## Recommendations
- Let content length influence type scale and measure.
- Treat font choice as part of hierarchy, rhythm, and cultural voice.
- Test real text, not pangrams alone.
- For multilingual work, check script-specific proportions, baselines, spacing, and hierarchy.
- Evaluate typography at the intended distance and medium.
