# Web / Product / UI-UX Context Playbook

## Context ladder
`control → component → screen → task flow → product → service/ecosystem`

## Ask
- What does the user want to accomplish?
- What happens before and after this screen?
- Where did the user come from?
- What state is the product in: empty/loading/error/success/offline?
- What device, viewport, input method, connectivity, and assistive technology are involved?
- Does content grow or vary dramatically?

## Apply
- Five Planes: strategy → scope → structure → skeleton → surface.
- Norman: signifiers, mapping, constraints, feedback, conceptual model.
- IA: organization, labeling, navigation, findability, sense of place.
- Responsive/adaptive behavior: reflow, reposition, resize, replace when appropriate.
- Accessibility: contrast, reflow, keyboard/input alternatives, target sizing, focus, semantics.

## Recommendations
- Design flows, not screenshots.
- Define transitions and state changes.
- Treat content as part of layout, not placeholder material.
- Test with actual devices and representative data.
