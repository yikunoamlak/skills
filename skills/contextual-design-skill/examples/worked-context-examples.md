# Worked Context Examples

## Example 1 — Logo

### Request
"Make my investment company logo more modern."

### Context ladder
`logo mark → identity system → investor communications → financial services category → trust/regulation/culture`

### Context insight
"Modern" is underspecified. In this category, credibility, legibility, restraint, data-rich communications, digital reproduction, and differentiation from generic finance tropes are more consequential than adding fashionable gradients.

### Recommendation
Design the mark with a system in mind: wordmark proportions, small-size behavior, monochrome use, app icon, presentation covers, reports, website, social avatars, signage, and motion. Then select a visual language whose geometry and typography reinforce the intended trust/modernity position.

## Example 2 — Website hero

### Request
"Make the hero section more impressive."

### Context ladder
`hero → landing page → acquisition journey → product/service → user's decision context`

### Context questions
- Where does traffic come from?
- What does the visitor already know?
- What must they understand in the first 5 seconds?
- Is the CTA a purchase, signup, contact, booking, or exploration?
- What evidence must appear before the CTA is credible?

### Recommendation
Treat the hero as the first move in a larger decision sequence, not as a poster. Improve message hierarchy, proof, task orientation, and transition into the next section before adding decorative animation.

## Example 3 — Video title animation

### Request
"Make this title animation cooler."

### Context ladder
`letter motion → title event → shot → sequence → story/tone → viewing platform`

### Context insight
A title can fail because it enters at the wrong emotional moment, steals attention from the image, conflicts with the music/sound design, or uses motion inconsistent with the film language.

### Recommendation
First determine what the preceding shot establishes and what the following shot needs. Then choose entrance timing, scale, motion path, easing, hold duration, contrast, and exit behavior as a continuation of the sequence.

## Example 4 — Architecture

### Request
"Design a beautiful pavilion."

### Context ladder
`detail → pavilion → site → circulation → landscape → neighborhood/city/culture`

### Context questions
- From where is it approached?
- What existing trees, views, paths, light, wind, climate, sound, and materials exist?
- What social behavior should happen there?
- Does it provide a useful threshold or only an object in the landscape?

### Recommendation
Let site and movement determine geometry, openings, shade, material, thresholds, and views. Test the building as part of the landscape rather than only as an isolated render.
