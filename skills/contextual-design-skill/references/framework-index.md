# Framework Index

## 1. Saarinen — next larger context
Core lens: understand a thing through the larger whole it belongs to.

Primary/authoritative reference:
- National Park Service: https://home.nps.gov/people/eero-saarinen.htm
- John Pawson, "Considering the next larger context" (2025): https://www.johnpawson.com/journal/considering-the-next-larger-context

Important attribution note: NPS attributes the teaching to Eero Saarinen's father, Eliel Saarinen. The phrase is widely reproduced as an Eero quotation, so verify attribution before publishing.

## 2. Contextual Design — Holtzblatt & Beyer
Core lens: field-based understanding of how people actually work in context, then use that evidence to drive design.

References:
- Springer overview: https://link.springer.com/book/10.1007/978-3-031-02207-4
- ACM CHI tutorial: https://chi1997.acm.org/proceedings/tutorial/kah2.html

Use when user behavior or real-world work practice is central.

## 3. Pattern Language — Christopher Alexander
Core lens: reusable patterns connect context, problem, forces, solution, and relationships across scales.

References:
- Cornell-hosted text: https://arl.human.cornell.edu/linked%20docs/Alexander_A_Pattern_Language.pdf
- Hillside pattern-writing guidance: https://www.hillside.net/index.php/a-pattern-language-for-pattern-writing

Use when a problem recurs and must be expressed as a contextual rule rather than one-off styling.

## 4. Systems thinking — Donella Meadows
Core lens: outcomes are produced by systems of relationships, stocks/flows, feedback, delays, rules, and structures; local parameter tweaks may have less leverage than structural changes.

Reference used in research:
- *Thinking in Systems* excerpts: https://studylib.net/doc/27898729/2009-meadows-thinking-in-systems

Use this lens to ask whether the artifact is merely a visible symptom of a deeper system problem.

## 5. Design Council Double Diamond
Core lens: expand and narrow understanding across Discover, Define, Develop, Deliver.

Reference:
- https://www.designcouncil.org.uk/resources/the-double-diamond/

Use to structure exploration and iteration, not to imply a rigid linear process.

## 6. UX Five Planes — Jesse James Garrett
Core lens: strategy, scope, structure, skeleton, surface.

Reference:
- https://pressbooks.bccampus.ca/technicalwriting2ed/chapter/6-3/

Use when a visual complaint may actually be a deeper product/structure problem.

## 7. Gestalt
Core lens: parts are perceived in relation; grouping and hierarchy emerge from proximity, similarity, continuation, closure, figure-ground, common region, connectedness, symmetry/order, and common fate.

References:
- Scholarpedia: https://www.scholarpedia.org/article/Gestalt_principles
- Nielsen Norman Group: https://www.nngroup.com/articles/gestalt-similarity/

## 8. Norman — action context
Core lens: affordances/signifiers, feedback, mappings, constraints, and conceptual models determine whether an interactive object makes sense.

Reference:
- Penn State-hosted text: https://media.aanda.psu.edu/sites/media/aa/files/documents/norman_design-of-everyday-things.pdf

## 9. Information architecture
Core lens: organization, labeling, navigation, findability, and sense of place operate at the level of the whole information environment.

References:
- VA Design System: https://design.va.gov/ia/
- O'Reilly, *Information Architecture for the World Wide Web*: https://www.oreilly.com/library/view/information-architecture-for/1565922824/ch04s02.html

## 10. Responsive / adaptive design
Core lens: design for the viewing/use environment, not one fixed canvas.

References:
- MDN: https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design
- Android adaptive design: https://developer.android.com/codelabs/adaptive-material-guidance

## 11. Accessibility
Core lens: access conditions are part of context, not a late-stage checklist.

Reference:
- W3C WCAG 2.2: https://www.w3.org/TR/WCAG22/

## 12. Architecture / critical regionalism
Core lens: place, climate, topography, material/tectonic qualities, culture, and urban fabric can be active design drivers rather than decorative references.

Reference:
- Springer, "Revisiting critical regionalism from an urbanistic perspective": https://link.springer.com/article/10.1057/s41289-025-00302-6

## 13. Service blueprint
Core lens: the customer-facing artifact is one layer in a larger delivery system involving visible staff/actions, backstage processes, support, and physical evidence.

Reference:
- UXAtlas: https://www.uxatlas.io/methods/service-blueprint

## How to choose a lens

Use the smallest set of frameworks that materially changes the design:

- **Artifact + composition:** Gestalt, pattern thinking
- **Human use / product / UI:** Norman, contextual inquiry, IA
- **Web/app:** Five Planes, IA, responsive/adaptive, accessibility
- **Brand:** system/touchpoint lens, pattern thinking, cultural context
- **Video/motion:** Gestalt/common fate, temporal/sequence context, platform context
- **Architecture:** scale ladder, site/place, climate, regional/contextual thinking
- **Service:** service blueprint + systems thinking
- **Cross-disciplinary:** Saarinen ladder + forces map + real-context test
