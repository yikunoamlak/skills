# Prompt Engineering — Afewerk Tekle Painting Style

## Core Principles

1. **Specificity over generality** — "graceful elongated neck" not "nice neck"
2. **Style establishment first** — "Oil painting in the style of Afewerk Tekle"
3. **Layer the details** — subject → anatomy → garments → background → lighting → color
4. **Choose your path** — Classical Realism OR Stained-Glass Cubism
5. **Oil painting texture** — Always mention visible brushwork, textured canvas

---

## Prompt Structure

Every prompt should follow this layered structure:

### Layer 1: Medium & Style
```
Oil painting in the style of Afewerk Tekle, monumental Ethiopian fine art
```

### Layer 2: Subject & Pose
What is being depicted, with Tekle-specific anatomy:
```
A dignified Ethiopian woman standing proudly, graceful elongated neck, large soulful expressive eyes
```

### Layer 3: Skin & Features
Rich, warm rendering:
```
rich golden-brown skin tones with soft glowing highlights
```

### Layer 4: Garments & Tilet
The cultural anchor:
```
wearing a glowing white habesha kemis with intricate gold and red woven tilet borders
```

### Layer 5: Background
Structured, monumental:
```
in the background, a serene Ethiopian landscape with blue lake and acacia trees
```

### Layer 6: Lighting & Color
The Tekle signature:
```
dramatic chiaroscuro lighting, luminous saturated colors, rich jewel tones
```

### Layer 7: Texture & Quality
Oil painting feel:
```
visible oil painting brushwork texture, dignified majestic composition
```

## Prompt Templates

### Template A: Classical Realism / Heroic Portrait
```
Oil painting in the style of Afewerk Tekle, monumental Ethiopian fine art. [SUBJECT], graceful elongated neck, large soulful expressive eyes, [SKIN TONE]. They are wearing [TRADITIONAL ETHIOPIAN CLOTHING with tilet details]. In the background, [SETTING]. Dramatic chiaroscuro lighting, luminous saturated colors, rich jewel tones, visible oil painting brushwork texture, dignified and majestic composition.
```

### Template B: Stained-Glass Cubism
```
Oil painting in the style of Afewerk Tekle, stained-glass cubist phase. [SUBJECT], deep warm skin tones, large expressive eyes. The composition is fractured by a striking web of sharp, intersecting dark geometric lines across the foreground and subject, creating a stained-glass effect. [CLOTHING DETAILS]. Vibrant glowing jewel-toned colors, high contrast, classical realism mixed with geometric abstraction, monumental Ethiopian fine art, visible oil painting texture.
```

### Template C: Allegorical / Narrative
```
Monumental oil painting in the style of Afewerk Tekle. [ALLEGORICAL SCENE]. Figures are statuesque with graceful elongated necks, wearing [GARMENTS with tilet]. Background features [SETTING]. Dramatic chiaroscuro lighting, luminous saturated jewel tones, rich oil painting texture, dignified heroic composition.
```

### Template D: Religious / Ceremonial
```
Oil painting in the style of Afewerk Tekle, monumental Ethiopian Orthodox art. [RELIGIOUS SCENE]. Figures draped in heavy volumetric robes of [COLORS] with intricate gold embroidery and tilet borders. Background features [CHURCH INTERIOR]. Classical realism, dignified postures, deeply saturated jewel tones, dramatic chiaroscuro, luminous oil painting texture.
```

### Template E: Landscape with Figure
```
Oil painting in the style of Afewerk Tekle, monumental Ethiopian fine art. [FIGURE] in the foreground of an idealized Ethiopian landscape. [LANDSCAPE — layered mountains, blue lake, acacia trees, warm sky]. Figure wears [WHITE GARMENT with tilet]. Dramatic chiaroscuro lighting, luminous saturated colors, rich jewel tones, visible oil painting brushwork, majestic composition.
```

## Advanced Techniques

### For Combining Classical + Cubist
```
Oil painting in the style of Afewerk Tekle, combining classical realism with stained-glass cubist elements. [SUBJECT] rendered in full classical detail, with geometric line overlay on [specific area — background, clothing, or one side]. Luminous colors, dramatic chiaroscuro, monumental composition.
```

### For Modern Subjects
```
Oil painting in the style of Afewerk Tekle, monumental Ethiopian fine art. [MODERN SUBJECT] rendered with Tekle's signature dignity — graceful elongated neck, large soulful eyes, rich warm skin tones. [Modern elements] with [traditional Ethiopian accents]. Dramatic chiaroscuro lighting, luminous saturated colors, rich jewel tones, visible oil painting texture.
```

### For Multiple Figures
```
Oil painting in the style of Afewerk Tekle, monumental Ethiopian fine art. [N] figures in [ARRANGEMENT]. Each with graceful elongated necks, large expressive eyes, rich warm skin tones. Wearing [INDIVIDUAL GARMENTS with tilet details]. Background: [SETTING]. Dramatic chiaroscuro lighting, luminous saturated jewel tones, rich oil painting texture, dignified composition.
```

## Platform-Specific Optimizations

### Midjourney
Append:
```
--ar 3:4 --s 250 --q 2
```
Portrait format suits monumental figures. Landscape format for scenes.

### DALL-E / ChatGPT
Use prompt as-is. DALL-E handles descriptive prompts well.

### Stable Diffusion
Add to positive prompt:
```
oil painting, textured canvas, visible brushwork, impasto, classical realism
```
Add negative prompt:
```
photography, photorealistic, 3d render, flat 2d, cartoon, anime, muted colors, pastel, desaturated, digital art, smooth gradients, vector, line art, sketch
```

### Flux
Use prompt as-is. Specify format (portrait/landscape).

### Ideogram
Use prompt as-is. Good for text elements if needed.

## Prompt Quality Checklist

Before finalizing any prompt, verify:

- [ ] Starts with "Oil painting in the style of Afewerk Tekle"
- [ ] Includes "monumental Ethiopian fine art"
- [ ] Subject described with dignity and heroic posing
- [ ] "Graceful elongated neck" mentioned
- [ ] "Large soulful expressive eyes" mentioned
- [ ] Skin tones specified as warm (golden/bronze/mahogany)
- [ ] Traditional garments described with tilet details
- [ ] White garments described as "luminous" or "glowing"
- [ ] Background is structured (architectural or landscape)
- [ ] "Dramatic chiaroscuro lighting" included
- [ ] "Luminous saturated colors" or "jewel tones" included
- [ ] "Visible oil painting brushwork" mentioned
- [ ] A distinct path chosen (Classical OR Cubist OR Combined)
- [ ] No forbidden terms (photorealistic, flat, digital, etc.)

## Common Prompt Mistakes

1. **Missing "oil painting"** — The medium must be specified
2. **No tilet description** — The woven borders are culturally essential
3. **Flat white fabric** — White must be described as luminous/glowing
4. **No chiaroscuro** — Without dramatic light/shadow, no volume
5. **Muted colors** — Must specify jewel tones, saturated, luminous
6. **Casual posing** — Must specify dignified, heroic, statuesque
7. **Empty background** — Must specify structured setting
8. **No skin tone** — Must specify warm golden/bronze/mahogany
9. **Missing texture** — Must mention visible brushwork, canvas texture
10. **Confusing with flat art** — Tekle is NOT flat 2D manuscript style
